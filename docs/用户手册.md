## 一、软件介绍

**财务工具箱**是一款面向 Windows 的离线财务小工具合集，帮助会计、出纳、财务人员快速完成人民币大写、价税分离、日期利息等日常计算。输入即得结果，支持一键复制，无需联网。

### 特点

| 特点 | 说明 |
|------|------|
| **完全离线** | 所有计算在本地完成，不上传任何数据 |
| **免费使用** | MIT 开源许可，无会员、无广告 |
| **绿色便携** | 便携版解压即用，删文件夹即卸载 |
| **中文友好** | 界面中文，符合国内财务书写习惯 |
| **轻巧顺手** | 小工具单页操作，支持 Excel 列粘贴 |

### 功能模块（规划）

| 模块 | 主要能力 | 状态 |
|------|----------|------|
| **金额文字** | 人民币大写、反查、支票日期大写、千分位 | 已上线 |
| **税务计算** | 价税分离、批量价税 | 已上线 |
| **日期利息** | 日期差、账期、利息、日历与节假日 | 已上线 |
| **贷款理财** | 等额本息 / 等额本金 | 已上线 |
| **折旧分摊** | 直线折旧、比例分摊 | 已上线 |
| **个税薪酬** | 工资个税累计预扣试算 | 已上线 |
| **校验格式** | 身份证、银行卡格式校验 | 已上线 |

### 系统要求

- **操作系统**：Windows 10 / 11（64 位）
- **内存**：建议 2 GB 及以上
- **磁盘空间**：约 30 MB（便携版）
- **网络**：不需要（完全离线）

## 二、安装与启动

### 便携版（推荐）

1. 下载 `财务工具箱-x.x.x-便携版.zip`
2. 解压到任意目录
3. 运行 `finance-toolbox.exe`（具体文件名以发布包为准）

1. 运行安装程序，按向导完成安装
2. 从开始菜单「inkdot」文件夹启动「财务工具箱」

## 五、工具说明

> 以下章节随开发进度补充。首期 MVP 完成后更新本节。

### 5.1 人民币大写

- 输入阿拉伯数字金额，点击「计算」或按 Enter
- 输出标准财务大写；支持负数与千分位逗号
- 「复制结果」写入剪贴板

### 5.2 大写反查

- 输入大写金额，反查为数字
- 可选填对照金额，自动核对是否一致
- 「由金额生成大写」可快速填充标准大写

### 5.3 支票日期大写

- 输入日期（如 `2026-06-12`），转换为支票用中文大写日期
- 「今天」填入当前日期

### 5.4 金额格式化

- **千分位**：添加千分位分隔符
- **去千分位**：移除逗号得到纯数字
- **批量**：每行一个数字，支持千分位或人民币大写

### 5.5 价税分离

- **已知含税价**：输入含税金额，计算不含税金额与税额
- **已知不含税价**：输入不含税金额，计算税额与含税合计
- 选择常用税率（13% / 9% / 6% / 3% / 1%）或自定义
- **批量**：每行「金额」或「金额,税率」，可复制为 TSV 粘贴回 Excel
- 界面显示「税率版本」，税率来自本地 `data/tax-rates.json`

### 5.6 工资个税

- 选择当前月份，输入税前月工资、专项扣除（社保公积金等）与专项附加扣除
- 采用综合所得**累计预扣法**试算（假定每月收入与扣除相同）
- 含基本减除费用 5000 元/月；界面显示「税率版本：2025」
- 结果仅供参考，以税务机关申报为准

### 5.7 证件校验

- **身份证**：校验 18 位格式、出生日期与校验码，并显示性别、地区码
- **银行卡**：Luhn 算法校验卡号格式，不验证银行归属
- 纯离线格式校验，不联网验真

## 六、常见问题

### 问：需要联网吗？

不需要。所有功能本地计算，断网可用。

### 问：我的输入会被上传吗？

不会。数据不离开您的电脑，且不写入磁盘（历史记录仅内存）。

### 问：大写金额与银行要求不一致怎么办？

请以贵司或银行最新规范为准；本工具采用常用《支付结算办法》写法。若发现个例错误，欢迎反馈。

### 问：税率 / 个税计算准确吗？

税率来自内置配置文件，版本号在界面显示。税法变更后需更新软件或配置文件。

### 问：能查验发票真伪吗？

不能。离线工具仅能做格式校验，真伪查询需登录税务平台。

## 附录 A：快捷键

| 快捷键 | 作用范围 | 说明 |
|--------|----------|------|
| **Enter** | 多数工具输入框 | 触发计算（多行文本框需 **Shift+Enter** 换行） |
| **Esc** | 输入框 | 清空当前输入与错误提示 |
| **Esc** | 打开的下拉菜单 | 关闭菜单 |
| **F4** | 带 📅 的日期输入框 | 打开月历选择 |
| **Alt+↓** | 带 📅 的日期输入框 | 打开月历选择 |
| **Esc** | 月历弹窗 | 关闭弹窗 |

> 本应用为窗口内快捷键，不支持全局热键（切换至其他程序后上述按键不会生效）。
