## 二、开发原则

1. **先文档后开发**：本计划与功能全景先行，再写代码
2. **小步迭代**：每阶段可独立交付、可发布便携版
3. **共用基础设施**：主题、标题栏、复制、toast、数字解析复用 `common.js`
4. **算法与 UI 分离**：`js/lib/` 纯函数，便于单测与 Rust 侧复用
5. **纯前端优先**：无文件 I/O 的工具不引入 Rust 命令
6. **离线约束**：见 [PRINCIPLES.md](../PRINCIPLES.md)

## 阶段 1：金额文字（MVP 核心）

**目标**：覆盖日常最高频的四个工具。

| 任务 | 说明 | 验收 |
|------|------|------|
| 1.1 `js/lib/decimal.js` | 安全解析金额字符串、精度 | 边界用例通过 |
| 1.2 `js/lib/rmb.js` | 数字 → 大写、大写 → 数字 | 符合常用财务写法 |
| 1.3 `js/lib/check-date.js` | 日期 → 支票大写 | 零壹拾贰等规则正确 |
| 1.4 工具页：人民币大写 | 输入、选项、结果、复制 | 实时或 Enter 计算 |
| 1.5 工具页：大写反查 | 反查 + 与正向核对 | 不一致提示 |
| 1.6 工具页：支票日期大写 | 日期选择器或文本输入 | 复制结果 |
| 1.7 工具页：金额格式化 | 千分位、小数位、批量行 | Excel 列粘贴 |
| 1.8 首页卡片 | 四工具标记「已上线」 | 导航正确 |
| 1.9 用户手册更新 | 四工具操作说明 | 文档与 UI 一致 |

**状态**：✅ 已完成
