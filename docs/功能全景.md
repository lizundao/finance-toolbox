## 一、金额与文字

日常最高频，首期 MVP 核心。

| 功能 | 说明 | 状态 |
|------|------|------|
| 人民币大写 | 数字 → 壹贰叁…圆角分整；支持负数、小数、亿级 | ✅ |
| 大写反查 | 大写金额 → 阿拉伯数字，用于核对凭证 | ✅ |
| 大小写核对 | 左右对照，不一致高亮 | ✅ |
| 支票日期大写 | `2026-06-12` → 贰零贰陆年陆月壹拾贰日 | ✅ |
| 金额格式化 | 千分位 / 去千分位、保留小数位 | ✅ |
| 批量金额 | 粘贴多行数字，批量转换大写或千分位 | ✅ |

### 算法要点（人民币大写）

- 遵循《支付结算办法》常用写法：零、壹、贰、叁、肆、伍、陆、柒、捌、玖、拾、佰、仟、万、亿、圆（元）、角、分、整
- 负数：前缀「负」或「（负数）」
- 超过精度：四舍五入或截断策略需在 UI 标明（默认保留两位小数）
- 边界：`0` → 零圆整；`0.00`；极大数亿级以上

## 八、明确不做

| 功能 | 原因 |
|------|------|
| 实时汇率 | 需联网或频繁手改，非核心 |
| 发票真伪查询 | 必须连接税务总局 |
| 电子税务局申报 | 复杂、需联网、合规风险高 |
| 完整财务/ERP | 与「小工具」定位不符 |

若用户需要汇率，可提供「本地汇率表 + 用户自行维护」作为远期轻量功能。

## 共用交互规范

所有工具页统一：

1. **输入区**：主输入 + 选项（税率、计息天数等）
2. **结果区**：大字号结果 + 辅助说明
3. **操作**：复制结果、复制全部、清空（Esc）
4. **批量**：支持从 Excel 粘贴一列，Tab/换行分隔
5. **快捷键**：Enter 计算，Ctrl+C 在结果区聚焦时复制
6. **历史**：内存最近 10 条，关闭即清空，不落盘
