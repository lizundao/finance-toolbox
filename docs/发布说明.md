# 财务工具箱 v0.1.0 — 发布说明

## 下载与安装

### 方式一：Windows 安装程序

1. 下载 `FinanceToolbox-0.1.0-setup-win-x64.exe`
2. 双击运行，按向导完成安装（默认安装到当前用户目录，无需管理员权限）
3. 从开始菜单「**inkdot**」文件夹启动「财务工具箱」

### 方式二：Windows 绿色版（便携版）

1. 下载 `FinanceToolbox-0.1.0-portable-win-x64.zip`
2. 解压到任意目录（路径尽量不要含特殊字符）
3. 运行 `finance-toolbox.exe`
4. 压缩包内附 `用户手册.md`、`发布说明.md`、`LICENSE`

> 绿色版不会写入注册表，删除文件夹即可卸载。

### 方式三：macOS（Apple 芯片）

1. 下载 `FinanceToolbox-0.1.0-aarch64.dmg`，拖入「应用程序」
2. 若系统提示「无法验证开发者」，可改用 `FinanceToolbox-0.1.0-aarch64.app.zip` 解压后运行，或执行 `xattr -dr com.apple.quarantine /Applications/Finance\ Toolbox.app`

> macOS 版本为未签名构建，首次打开的拦截提示属正常现象。

## 功能一览

### 金额与文字

- 人民币大写、大写反查、大小写核对
- 支票日期大写
- 金额格式化（千分位 / 去千分位 / 批量）

### 税务

- 价税分离（含税 ↔ 不含税，常用税率与自定义）
- 批量价税，可复制 TSV 回 Excel

### 日期与利息

- 日期差（自然日 / 工作日）
- 账期计算
- 利息计算（360 / 365 计息基数）
- 月历与节日提醒
- 节假日设置（放假 / 调休，本地保存）

### 贷款 / 折旧 / 分摊

- 等额本息、等额本金（含还款计划表）
- 直线折旧
- 比例分摊（尾差调整）

### 个税与校验

- 工资个税（综合所得累计预扣法试算）
- 身份证格式校验（出生日期、校验码）
- 银行卡 Luhn 校验

### 其他

- 中英文界面、深色 / 浅色主题
- 关于页、MIT 许可证全文

## 使用提示

1. **Enter** 在多数工具中触发计算，**Esc** 清空当前输入
2. 日期输入框旁 📅 按钮，或 **F4** / **Alt+↓** 打开月历选择
3. 批量工具支持从 Excel 复制一列后粘贴
4. 税率、个税表与节假日数据来自本地 JSON 配置（`data/`），可按政策变化自行更新；节假日覆盖 2001–2027 年，超出范围的年份界面会给出提示
5. 证件校验仅做离线格式验证，不联网验真

---

## 已知限制

- 桌面版支持 Windows 与 macOS（Apple 芯片），暂不提供 Linux / 移动端版本
- 个税试算假定每月收入与扣除相同，结果仅供参考
- 银行卡校验不验证银行归属；发票不做验真
- 未签名安装包时，Windows 可能提示「未知发布者」，macOS 可能提示「无法验证开发者」
- 节假日数据覆盖 2001–2027 年；超出范围的年份会提示工作日结果为估算值
- 金额计算上限约 90 万亿元，超限会明确拒绝而非给出不精确结果

```bash

npm run release:portable   # 上述 + 整理 release/ 目录与便携 zip
```
