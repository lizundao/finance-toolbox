# 品牌与视觉

本文档定义财务工具箱自身的标识、配色与界面结构。改动视觉元素时以此为准。

## 两套标识（勿混用）

| 资源 | 文件 | 用途 |
|------|------|------|
| **应用 Logo** | `public/logo.svg` | 标题栏、侧边栏、任务栏图标、Favicon |
| **网站品牌 Logo** | `public/inkdot.png` | **仅「关于」页**墨点品牌展示 |

根目录 `inkdot.png` 为源文件副本；构建与运行时统一引用 `public/inkdot.png`。

---

## 应用 Logo（logo.svg）

图标含义：三列计算器 / 电子表格网格，契合「财务计算小工具」定位。

Logo 使用**固定品牌色**（非 `currentColor`），在深色、浅色 UI 背景下均可辨认；与界面交互主色 `--accent`（蓝）形成互补，财务工具箱以珊瑚红为品牌识别色。

| 色值 | 用途 |
|------|------|
| `#E8483F` | 主色：外框、按键块 |
| `#FFABA8` | 浅色：显示屏细条、高光细节 |

### 使用位置

| 位置 | 尺寸建议 |
|------|----------|
| 标题栏 | 18×18 |
| 侧边栏品牌区 | 32×32 |
| 首页功能卡片（可选） | 24×24 |
| 应用图标（打包） | 由 `logo.svg` 生成 32/128/256 PNG 与 `.ico` |

### HTML 引用示例

```html
<img src="/logo.svg" alt="" class="sidebar-logo" width="32" height="32" />
```

无需对 Logo 容器设置 `color`；图标自带品牌色。

### 应用图标生成

发布前从 `logo.svg` 生成 Tauri 所需图标集：

- `src-tauri/icons/32x32.png`
- `src-tauri/icons/128x128.png`
- `src-tauri/icons/128x128@2x.png`
- `src-tauri/icons/icon.ico`
- `src-tauri/icons/icon.icns`（macOS 打包需要）

使用 `npm run icon` 或 Tauri CLI `tauri icon public/logo.svg`。

## 网站品牌 Logo（inkdot.png）

**文件**：`public/inkdot.png`

墨点 inkdot 官网吉祥物，用于「关于」页品牌区，**不要**替换标题栏/侧边栏的应用 Logo（`logo.svg`）。

### 关于页引用

```html
<div class="about-brand">
  <img
    src="/inkdot.png"
    alt="墨点 inkdot 网站 Logo"
    class="about-logo"
    width="56"
    height="56"
  />
  <div>
    <div class="about-brand-name">墨点 inkdot</div>
    <div class="about-brand-tagline">小工具，一点就够用 · inkdot.cn</div>
  </div>
</div>
```

对应样式定义在 `css/app.css` 的 `.about-brand`、`.about-logo`、`.about-brand-name`、`.about-brand-tagline`。

## 配色与布局

全局设计 token 定义在 `css/app.css`：

| Token | 用途 |
|-------|------|
| `--accent: #4361ee` | 交互主色、激活导航、主按钮（与 Logo 珊瑚红互补） |
| Logo `#E8483F` | 应用 Logo（`logo.svg`）品牌色 |
| `--bg` / `--bg-sidebar` | 页面与侧边栏背景 |
| `--bg-card` | 工具卡片、表单区 |
| `--text` / `--text-muted` | 正文与辅助文字 |
| `--radius: 10px` | 圆角 |
| `--sidebar-w: 200px` | 侧边栏宽度 |

支持 `[data-theme="dark"]`（默认）与 `[data-theme="light"]` 切换，localStorage 键名：`finance-toolbox-theme`。初始化逻辑位于 `public/theme-init.js`，需在样式加载前同步执行以避免浅色主题闪屏。

## 布局结构

```
┌─────────────────────────────────────────────┐
│ 标题栏：Logo + 财务工具箱 + 菜单 + 窗口按钮 │
├──────────┬──────────────────────────────────┤
│ 侧边栏   │ 主内容区（当前工具视图）          │
│ · 首页   │                                  │
│ · 工具…  │  输入卡片 + 结果卡片 + 复制按钮   │
│          │                                  │
└──────────┴──────────────────────────────────┘
```

无系统装饰边框，标题栏使用 `data-tauri-drag-region` 支持拖拽，窗口按钮通过 `@tauri-apps/api/window` 控制。
